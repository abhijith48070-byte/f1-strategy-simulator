F1 Strategy Simulator:

A machine learning project built using FastF1 race data from the 2024 Monaco Grand Prix.

Features:

* Pit stop prediction using Random Forest
* Tyre degradation analysis
* Lap time prediction using Gradient Boosting
* Basic pit window simulation

Technologies Used:

* Python
* FastF1
* Pandas
* Scikit-learn
* Matplotlib

Models:

Classification;

* Random Forest Classifier

Regression;

* Gradient Boosting Regressor

Future Improvements

* Safety car strategy
* Weather effects
* Traffic modeling
* Multi-race analysis
